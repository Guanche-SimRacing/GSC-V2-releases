# Changelog

Todas las novedades notables de GSC V2 se documentan aquí.

## [v2.0.0-beta.1] — 2026-09-13

Primera versión pública, en beta. Solo incluye la versión **Free**
— Pro llegará en una próxima actualización.

### Incluye

- Configuración completa de proyectos: placa, componentes, diagrama
  de cableado y carga de firmware directamente desde la app.
- Soporte para Matriz de Botones (hasta 4×4) y Rotary Encoder.
- Generación y carga de firmware sin necesidad de tener Python ni
  Arduino IDE instalados — la app se instala sola las herramientas
  de Arduino que necesita la primera vez.
- Identidad USB personalizada para productos Guanche.

### Conocido / en progreso

- La versión Pro (resto de componentes: botones, sensores Hall,
  joystick, interruptor rotativo de 12 posiciones, célula de carga,
  y matrices de más de 4×4) todavía no está disponible para comprar.
- Si encuentras algún problema, cuéntanoslo por
  [Discord](https://discord.gg/MDgCRAzTWJ) o abriendo un
  [Issue](../../issues).
